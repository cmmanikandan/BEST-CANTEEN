# BEST-CANTEEN

Next-Gen Digital Campus Canteen Ordering & QR Token Management Platform.

## Key Features
- **Cashless Ordering**: Razorpay Payment Gateway integration (UPI, Cards, Netbanking).
- **Cryptographic QR Tokens**: Instant token generation for lightning-fast counter collection.
- **Smart Meal Timings**: Dynamic breakfast, lunch, snacks, and dinner meal schedule tracking.
- **Role-Based Portals**:
  - **Customer Portal**: Live menu, cart, digital token feed, order tracking, and PWA support.
  - **Counter Staff Portal**: High-speed token scanning, order verification, and queue status.
  - **Admin Panel**: POS Cash Register, menu management, live revenue analytics, and server accounts.
- **Firebase Authentication**: Email/Password and Google OAuth sign-in.
- **Supabase Integration**: PostgreSQL real-time database and food image CDN storage.
- **Progressive Web App (PWA)**: Standalone home screen installation with service worker.

## Tech Stack
- **Framework**: Next.js 14 (App Router), React 18, TypeScript
- **Styling**: Tailwind CSS, Framer Motion
- **Auth**: Firebase Auth
- **Database & Storage**: Supabase (PostgreSQL, Realtime, Storage)
- **Payments**: Razorpay Live Gateway
